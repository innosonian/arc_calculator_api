# 확정 결정과 미정 사항

현재 기준: 2026-09-28까지의 사용자 확정 답변과 로컬 구현. 날짜가 더 최근인 AI 문서만으로 사용자 결정을 대체하지 않는다. 아래는 **사용자 결정**, **현재 구현**, **미정 사항**을 구별한 기록이다. 설명을 줄이기 위해 구현 세부는 [구조·보안](ARCHITECTURE.md), 필드·자료형은 [상세 API](ARC_MOCK_IMPLEMENTED_API_CONTRACT_KO.md)에 둔다.

## 6. 외부 계약과 후속 확인

현재 API와 구조는 [앱 API 명세](APP_API.md), [구조](ARCHITECTURE.md)를 따른다. 과거 설계 초안·질문 반복·단계별 작업 지시는 제거했다. 결정 ID는 기존 코드·시험에서 추적할 수 있도록 유지한다. 확정 사항을 다시 질문하거나 현재 코드에 맞춰 사용자 정책을 바꾸지 않는다.

CPR 완료 규칙(Q22/U01), 생성 응답 유실과 만료가 겹친 복구(Q24), 실제 ARC 학생 인증·공급·제출 규격, 콘텐츠 관측, 진도 충돌·평가 교체 의미, 앱 전환과 운영 조건은 남아 있다. 기술적 오류 복구와 교육 정책을 구별한다.

## 7. 현재 구현과 승인 범위

`course_v2`는 명시적으로 주입한 공급자와 실제 누적 바이너리 계산을 사용한다. D103에 따라 로컬 기본 실행과 AWS API는 `/api/v2`만 조립하며 `/mock/v1`·`/cpr-analysis`는 404다. 실제 앱 전환 일정·인수는 RQ21을 따른다. 로컬과 AWS Dev는 D93의 `course_v2_dummy` 임시 과정 15개(기존 계산 정의, 각 훈련→최종평가)를 같이 쓴다. 영상·문서 자료와 공식 ARC 배정은 이 임시 카탈로그에 포함하지 않는다. 2026-09-23 사용자 출력으로 Dev stage 생성·직접 Lambda 로그인/조회·HTTPS 미로그인 차단을 확인했으며 전체 AWS 인수는 진행 중이다. 구현·로컬 검증·사용자 실행 AWS 결과는 [VALIDATION](VALIDATION.md)에 구별해 모은다.

G-ARC(공식 인증·공급 계약), G-CONTENT(앱 콘텐츠 관측), G-GOAL(CPR·2인/AED 완료 기준), G-REVISION(외부 진도 충돌·평가 교체 의미), G-DELIVERY(실제 제출 계약), G-RELEASE(실물 앱·AWS·운영 전환)를 구별한다. 계약이 없다는 이유로 빈 성공·새 수강·임의 Pass/Fail·가짜 점수·제출 성공을 만들지 않는다. AI 역할의 PASS는 사람의 인증이나 배포 승인이 아니다.
