# 확정 결정과 미정 사항

통합 기준: 2026-09-10 사용자 대화와 승인된 로컬 구현. 날짜가 더 최근인 AI 문서만으로 사용자 결정을 대체하지 않는다. 아래는 **사용자 결정**, **현재 구현**, **미정 사항**을 구별한 기록이다. 설명을 줄이기 위해 구현 세부는 [구조·보안](ARCHITECTURE.md), 필드·자료형은 [상세 API](ARC_MOCK_IMPLEMENTED_API_CONTRACT_KO.md)에 둔다.

## 3. 저장·보호·작업 방식

| ID | 유지할 결정 | 근거·현재 경계 |
|---|---|---|
| D28 | 원본·결과 보관·삭제와 운영 규격은 HSTM 기준에 맞춤 | R13/R15. 기존 저장 경로 규칙·로그 재현 목적 유지. 실제 lifecycle/삭제 일수·한도는 소스만으로 확인되지 않아 미정 |
| D29 | 차트 링크300초 유지, 로그아웃으로 남은 수명 단축 안 함 | R14/B04. 파일 삭제 시각과 링크 만료는 다름. 새 링크에는 유효한 시도 접근 권한 필요 |

| D32 | local/dev/beta/prod 각각 검증 가능해야 함 | 현재 local 완료, 나머지는 실행 구성·실자원·권한·배포·실제 인수 후속 작업 |
| D33 | 구현은 기존 구성 재사용·미완성 연결 중심, 실제 검증과 분석을 구별 | 사용자 요청한 단계별 상호 검토/CTO 심사 기록은 검증 요약 및 로컬 원본에 보존 |

| D35 | 핵심 Markdown9개 유지. 원본과 진행 JSON·patch는 로컬에 보관하고 Git에서 제외 | 2026-09-10 문서 정리 지시. 코드/테스트가 읽는 필수 계약 JSON과 실측/회귀 fixture는 별도 |
| D36 | DB 저장 대상은 앱의 훈련 진도·계산 결과·운용 로그. 이번에 로컬 구현·검증까지 진행 | N01~N06 확정. 기존 상태/결과 참조 DB·비공개 파일 코드 재사용. 주요/정제된 상세 진단의 로컬 DB 기록을 추가. 로그 장애로 정상 훈련을 막지 않으며, 기간 확정 전 자동 삭제 없음. 개발 과정 JSON·patch는 로컬 보관. AWS 연결은 후속 |
| D37 | 2026-09-11 품질 개선 작업의 AWS 범위는 기존 구성 기반 제안과 안전한 준비까지만 | 최신 사용자 답변: 운영값·배치는 아직 미정. 실제 AWS 접근·자원 변경·배포, commit·push 금지. 미정 한도·접근 정책을 임의 확정하지 않음 |

현재 로컬 입력1,000,000 bytes·객체8,000,000 bytes·객체 저장소1 GiB·lease60초는 명시된 조절 가능한 **로컬 구현 기본값**이다. HSTM/AWS 운영 수치나 새로운 사용자 훈련 정책으로 승격하지 않는다.

## 6. 출처와 로컬 원본

기존 A01~A08, P1~P4, R01~R16, B01~B06 및 후속 정정은 위 내용과 API·구조 문서로 통합했다. 원문은 `.documentation-backup/2026-09-10-document-consolidation/originals/`에 기존 경로대로 있다. `ORIGINALS.json`이 파일별 hash·크기·기존 Git blob을 기록한다. 이 폴더는 로컬에만 존재하며 다른 개발자의 checkout에는 없을 수 있다. 새 작업은 핵심9개만으로 시작할 수 있어야 한다.

과거 문서를 직접 실행 지침으로 사용하지 않는다. 자료형·응답 같은 구체 계약은 상세 API에서, 승인/시험의 한계는 검증 요약에서 확인한다. 후속 사용자 답변이 오면 해당 행의 상태와 관련 문서를 함께 갱신한다.
